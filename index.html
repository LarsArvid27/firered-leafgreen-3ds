Install

  1. Your 3DS needs custom firmware and the Homebrew Launcher.
  2. Extract the ZIP to the root of the SD card. It holds a 3ds folder: FireRed goes into 3ds/firered3ds/, LeafGreen into 3ds/leafgreen3ds/. Each game keeps its own save there.
  3. Open the Homebrew Launcher and start FireRed 3DS or LeafGreen 3DS.
  4. Updating later: build again with the same ROM and extract over the old files. Your save is kept.

Questions

How do I know if my ROM is version 1.0?

Choose it above: the page reads its header and checksum and tells you. Version 1.1 cartridges and dumps exist for both games and are refused, because the game data is rebuilt byte for byte from version 1.0.

Is my ROM uploaded anywhere?

No. Everything runs inside your browser. The ROM is read into memory, the game data is rebuilt from it there, and only the result is offered to you as a download. Nothing about the ROM is sent to any server.

What does the download contain?

The game's 3DS program and a data pack made from your ROM. The program on its own contains no game data, which is why your ROM is needed.

Following Pokémon look like HeartGold/SoulSilver's. Where do they come from?

The builder downloads the HeartGold/SoulSilver overworld sprites from the pret decompilation project while it builds, checks each one against a pinned checksum and converts it. If the download fails the game still works, just without followers.

Does it run on an emulator?

It is a 3DS homebrew program, so it runs on 3DS emulators that support homebrew (for example Azahar) as well as on real hardware.
